# Video Conferencing Application

A real-time video conferencing web application that allows users to create and join meeting rooms.

## Features

- User authentication
- Create meeting rooms
- Join meeting rooms
- Real-time video/audio communication
- Real-time chat
- Mute/unmute microphone
- Enable/disable camera
- Leave meeting
- Socket.IO based real-time communication
- WebRTC based peer-to-peer communication

## Tech Stack

### Frontend
- React.js
- React Router
- Socket.IO Client
- WebRTC

### Backend
- Node.js
- Express.js
- Socket.IO
- MongoDB
- JWT
